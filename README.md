# EDPP - Event Driven Payment Platform

Event-driven microservices platform simulating a real-world payment system using Kafka, CDC, and microservices architecture.

## Services
- Order Service
- Payment Service
- Inventory Service
- Notification Service
- Analytics Service

## Tech Stack
- Java / Spring Boot
- Apache Kafka
- Debezium (CDC)
- Docker
- Terraform
